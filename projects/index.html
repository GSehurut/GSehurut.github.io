How to contribute

  1. Pick a project

    Read its README and roadmap to see where it is heading.

  2. Find an issue

    Issues labelled good first issue are scoped for newcomers. Comment to claim one.

  3. Open a pull request

    Follow the contributing guide. Every PR runs tests and linting automatically.

Have an idea that isn't on a roadmap? Open an issue on the repository or get in touch.
